# Тектон — сайт фасадных систем

Одностраничный сайт на Vite + three.js + GSAP + Lenis.

```
npm install
npm run dev      # http://localhost:5180
npm run build    # сборка в dist/
```

Публикуется на GitHub Pages автоматически при пуше в `main` (`.github/workflows/pages.yml`).
Изображения объектов и производства — концептуальные визуализации.
